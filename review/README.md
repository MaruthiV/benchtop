# How the source assessments were done

Codex compared each generated miniature with the archived paper version before qualification. The checks cover the mechanism, baseline, shared randomness, held-out metric, effect margin, execution and shortcuts. Small numerical controls were used where they could resolve a specific implementation question.

Maruthi approved the recommendations and authorized the remaining assessments. These are assistant-prepared, owner-authorized decisions. They are not independent human fidelity reviews or peer reviews. This is a limitation relative to the original protocol's human review plan.

The original record schema calls the approving owner a human reviewer. That field describes the authorization role. It does not establish who read the source, and it must not be interpreted as independent scientific validation. Original decisions, hashes and timestamps are preserved. Later records explicitly identify Codex as the assessor under standing owner authorization.

An excluded generated miniature is not a rejected paper. A null qualification is not a defect. Neither favorable qualification nor owner approval establishes that a toy lab replicates the paper's findings.

The public supplement preserves the source assessment, its source/draft hashes, stated scope and decision. Private file references are omitted. Full downloaded papers, provider transcripts, account details and connection credentials are not part of the release.
